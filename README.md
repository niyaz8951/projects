# projects - DAME Projects tile

The team's project register inside DAME HUB: a list of projects, each opened from the list with its details and history, and in later steps its location on a map, a compliance review and product options. Pages are plain HTML, CSS and JS behind the core guard; every row of data lives in Supabase (schema `projects`, functions `public.projects_*`). See `docs/TILE.md` for what it does, its rights and its data, and `docs/STATUS.md` for what is built and what the owner should check.
