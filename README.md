# projects - DAME Projects tile

The team's Projects tool inside DAME HUB, moved from Thinkneering: a register of projects, each holding the datasheets and specifications of one job, the compliance record with its helps (datasheet values, approved Product Options, library answers), the factory compliance library and Product Options, and the Excel downloads. Step 1 (register, project page, visibility, sharing, products and factories) and step 2 (datasheets read in the browser into tables saved in the project, the row mapping, Product Options collection) are built; the rest follows in order. Pages are plain HTML, CSS and JS behind the core guard; every row of data lives in Supabase (schema `projects`, functions `public.projects_*`). See `docs/TILE.md` for what it does, its rights and its data, and `docs/STATUS.md` for what is built and what the owner should check.
