# projects - DAME Projects tile

The team's Projects tool inside DAME HUB, moved from Thinkneering: a register of projects, each holding the datasheets and specifications of one job, the compliance record with its helps (datasheet values, approved Product Options, library answers), the factory compliance library and Product Options, and the Excel downloads. Steps 1-4 (register and project page; datasheets read in the browser into tables saved in the project; specifications converted into clauses, the record with its helps, Focus mode and the Excel downloads; Compliance review of the factory library) are built; Product Options follows. Pages are plain HTML, CSS and JS behind the core guard; every row of data lives in Supabase (schema `projects`, functions `public.projects_*`). See `docs/TILE.md` for what it does, its rights and its data, and `docs/STATUS.md` for what is built and what the owner should check.
